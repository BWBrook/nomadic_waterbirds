# Nomadic Waterbirds

Placeholder repository for the project "Hydrological reaction norms of Australia's nomadic waterbirds".

The project aims to estimate how Australian waterbird species and functional groups respond to current and lagged wetland inundation, and to classify wetlands by ecological roles such as drought refugia, flood-pulse foraging sites, breeding-support wetlands, stepping-stones, and uncertain or weakly used sites.

The initial project statement is in [docs/project_brief.md](docs/project_brief.md).
