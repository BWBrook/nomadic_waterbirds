# Literature Support

This directory stores external literature-support artefacts used for planning
and manuscript development.

- [deep_research_hydrological_reaction_norms_2026-05-31.md](deep_research_hydrological_reaction_norms_2026-05-31.md):
  broad ChatGPT Deep Research review of hydrological reaction norms for
  Australia's nomadic waterbirds.
- [deep_research_hydrological_reaction_norms_triage_2026-05-31.md](deep_research_hydrological_reaction_norms_triage_2026-05-31.md):
  supervisor triage note describing how the review should and should not be
  used.
- [source_verification_queue_2026-05-31.md](source_verification_queue_2026-05-31.md):
  priority queue for directed source verification before manuscript claims are
  made from the review.

## Use Policy

Broad Deep Research reports are orientation and planning artefacts. They can
shape goals, modelling design, conceptual figures, and literature-search
priorities. They are not claim-grade evidence until individual sources and
citation details have been verified.
