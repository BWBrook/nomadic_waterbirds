# Project Documents

This directory holds the operating and planning documents for the nomadic
waterbirds project.

- [project_brief.md](project_brief.md): original project statement.
- [analysis_plan.md](analysis_plan.md): research questions, estimands, model
  architecture, and staged analysis phases.
- [data_stream_register.md](data_stream_register.md): proposed data streams,
  access routes, permissions, inclusion rules, and next actions.
- [source_evidence_register.md](source_evidence_register.md): official-source
  evidence checked for data-access and wetland-unit feasibility.
- [data_access_feasibility.md](data_access_feasibility.md): feasibility memo
  for candidate hydrology, biodiversity, climate, and static covariate streams.
- [wetland_unit_feasibility.md](wetland_unit_feasibility.md): comparison of
  spatial-support options for prototype wetland units.
- [prototype_scope.md](prototype_scope.md): recommended smallest defensible
  prototype scope for the next goal.
- [decision_memo_002.md](decision_memo_002.md): supervisor-facing Goal 002
  recommendation.
- [prototype_wetland_unit_crosswalk.csv](prototype_wetland_unit_crosswalk.csv):
  machine-readable Goal 003 candidate wetland-unit crosswalk.
- [prototype_wetland_unit_crosswalk.md](prototype_wetland_unit_crosswalk.md):
  interpretation, candidate-selection rationale, and unit caveats for the
  crosswalk.
- [hydrology_metric_spec.md](hydrology_metric_spec.md): monthly DEA Water
  Observations metric and quality-rule contract.
- [product_access_probe_003.md](product_access_probe_003.md): record of Goal
  003 public metadata and product-access checks.
- [decision_memo_003.md](decision_memo_003.md): supervisor-facing Goal 003
  recommendation.
- [hydrology_smoke_test_report.md](hydrology_smoke_test_report.md): Goal 004
  hydrology-only extraction smoke-test report.
- [hydrology_smoke_test_manifest.json](hydrology_smoke_test_manifest.json):
  machine-readable Goal 004 provenance and resource manifest.
- [hydrology_smoke_test_summary.csv](hydrology_smoke_test_summary.csv):
  machine-readable Goal 004 candidate/support/month summary table.
- [reproducibility_plan.md](reproducibility_plan.md): repo structure,
  environment strategy, provenance, generated artefacts, and manuscript build
  pathway.
- [validation_plan.md](validation_plan.md): spatial, temporal,
  hydrological-event, independent-data, and synthetic-bias validation.
- [manuscript_plan.md](manuscript_plan.md): contribution, claim evidence,
  journal framing, and figure/table plan.
- [decision_log.md](decision_log.md): dated foundation decisions.
- [goals/](goals/): goal packets and execution logs.
