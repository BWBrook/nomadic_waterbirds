## Register Rules

- Update this file before any data acquisition or processing.
- Add file locations, request dates, license notes, and exclusion decisions when
  each stream moves from planned to acquired or rejected.
- Keep raw data outside Git unless a later license review explicitly permits a
  small public fixture.
- Record sensitive-species handling before any biodiversity export enters the
  repo.
